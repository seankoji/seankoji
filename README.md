# Sean Carey

Senior engineering leader, hands-on. I lead product technology teams for a living and still ship code most days, lately a lot of it with coding agents in the loop. Sydney, Australia.

Most of my current public work lives in the [seankoji-com](https://github.com/seankoji-com) organisation. This account is the older drawer: a few current tools, some forks kept for reference, and learning projects from 2017 onward. If you are evaluating my work, start with the organisation.

## Start here

- **[Tanks](https://github.com/seankoji-com/tanks)**, live at [tanks.seankoji.com](https://tanks.seankoji.com). Sydney fuel prices after discounts, price-cycle position and experimental forecasts, collected every 20 minutes and served from a Raspberry Pi at home.
- **[t3-plugins](https://github.com/seankoji-com/t3-plugins)**. Six workflows that make coding agents produce evidence, tests and review tied to the exact revision, instead of confident summaries.
- **[FrugalBar](https://github.com/seankoji-com/frugalbar)** and **[Freshen](https://github.com/seankoji-com/freshen)**. AI quotas in the macOS menu bar, and one terminal screen for a folder full of Git repositories.
- **[recovery-lab](https://github.com/seankoji-com/recovery-lab)**. A drill that proves an encrypted backup restores to a working application, receipt included.
